# CJ26
CJ26 global PDF analysis with all 6 GeV JLab DIS and the recently published 12 GeV measurements.

## PDF sets:

| ID | Set name |      |
| :---     | :---    | :---    |
| 12700  | CJ26_mHT  | With multiplicative, isospin-dependent (p$`\neq`$n) HT corrections |
| 12720  | CJ26_aHT   | With Addtive, isospin-dependent (p$`\neq`$n) HT corrections |

## Structure functions:
Structure function grids are available in LHAPDF format for proton, neutron, and deuteron. Structure function flavor indexes follow the txgrids convention (https://jeffersonlab.github.io/txgrids/_build/html/grids.html).

| 12727  | CJ26_aHT-FdNC  |
